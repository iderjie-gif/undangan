UNDANGAN WAWAN & FITRI — GITHUB PAGES

CARA UPLOAD:
1. Buat repository baru di GitHub, misalnya: undangan-wawan-fitri
2. Pilih Public jika memakai GitHub Free.
3. Upload SEMUA file di folder ini ke root repository:
   - index.html
   - padapadakui.mp3
   - .nojekyll
4. Buka Settings > Pages.
5. Build and deployment: Deploy from a branch.
6. Branch: main, folder: /(root), lalu Save.
7. Tunggu beberapa menit, lalu buka URL GitHub Pages yang diberikan GitHub.

PERSONALISASI NAMA TAMU:
Tambahkan ?to=Nama%20Tamu pada URL.
Contoh:
https://USERNAME.github.io/undangan-wawan-fitri/?to=Andi%20dan%20Keluarga

CATATAN:
- Musik akan mulai setelah tombol BUKA UNDANGAN ditekan.
- Jangan mengganti nama padapadakui.mp3 kecuali nama file juga diubah di index.html.
- File netlify.toml tidak diperlukan untuk GitHub Pages dan sengaja tidak disertakan.
